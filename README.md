# Pankaj_Store_Analysis(Interactive Dashboards Creating Using PowerBI

## Objective
- Owner of Pankaj Store wants us to help them create a dashboards to track and analyze their online sales accross india.

 ## sample question
- What is the total profit generated across all sales?
-How can we calculate the total amount of sales in the dataset?
-What is the sum of quantity sold across all categories?
-How is the Average Order Value (AOV) calculated in this dashboard?etc
